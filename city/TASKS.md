## 再開手順(次のセッションはここから)
1. `python3 city/tools/build.py` で `city/dist/index.html` を生成(単体HTML)。
2. `cd city && node tools/shot.mjs tools/scen/nav2.mjs` で実機相当(Pixel 7 横)の操作確認。スクショは `$OUT`。
3. 下の「進行中」の先頭から続ける。

## 構成メモ
- `src/modules/*.js` は esbuild バンドルを分割したもの。全モジュールが1つのIIFEのスコープを共有。
  新規モジュールは `ORDER.txt` の `999_end.js`(boot と IIFE 終端)より前に追加する。
- `window.NLS` … 実行中ゲームのハンドル(G=Game, R=Renderer, U=UI状態, nav=自動移動API)。
- 主人公の移動: `056_motion.js moveHero()`。入力は `127_main.js step()`。
- 自動移動: `128_autonav.js`(navTo / navStop / onTap / tapPick / destSheet / goHome)。
